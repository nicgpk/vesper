# Sample backdrop

`dunes.jpg` is a locally hosted Unsplash photograph, downloaded from
https://images.unsplash.com/photo-1473580044384-7ba9967e16a0
and resized to 1400 pixels wide. Use is covered by the
[Unsplash License](https://unsplash.com/license).

The image is decorative, has an empty alternative, and ships locally so the
component preview makes no runtime request to an image service. It is not a
Liqui asset. The material treatment is inspired by https://liqui.design/docs/components;
Vesper retains Astryx's component implementations and does not copy Liqui source.
